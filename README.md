Currency Converter (API + Tkinter)

A simple desktop application that converts currencies using real-time exchange rates from an online API.

This project was built with Python and demonstrates how to integrate APIs with a graphical user interface using Tkinter.

Features

Real-time currency conversion

Integration with an external exchange rate API

Simple graphical interface built with Tkinter

Error handling for invalid currency codes

Clean and beginner-friendly Python code

Technologies Used

Python

Tkinter

Requests

REST API

How It Works

The user enters:

Base currency (example: USD)

Target currency (example: BRL)

Amount to convert

The program sends a request to an exchange rate API.

The API returns the latest currency rates in JSON format.

The program calculates and displays the converted value.

Example

Base Currency: USD
Target Currency: BRL
Amount: 100

Result:
100 USD = 501.23 BRL

Installation

Install the required library:

pip install requests

Run the program:

python currency_converter.py
